## 阶段一：项目初始化与内核骨架 (2026-05-20 ~ 2026-05-22)

### 2026-05-20 — 项目启动

**提交**: `61899b7` SOS operating system — full project snapshot
**提交**: `b43cca4` Initial commit

完成内容：
- 确立项目骨架与目录结构（hal/hsai/kernel/user/include 分层）
- 实现 RISC-V64 和 LoongArch64 双架构 HAL 层启动代码
  - `entry.S` 内核入口、栈初始化、跳转 `sos_start_kernel`
  - `switch.S`/`swtch.S` 上下文切换汇编
  - `kernelvec.S` 内核异常向量表
  - `trampoline.S` 用户态↔内核态切换蹦床
  - `tlbrefill.S` LoongArch TLB 重填处理器
- 实现 HSAI 中断/Trap 分发框架（`usertrap`/`kerneltrap`/`devintr`）
- Buddy System 物理内存管理
- 多级页表遍历与映射（RISC-V 三级 + LoongArch 四级）
- 进程池（NPROC=64）+ 轮转调度器原型
- UART 控制台输出
- EXT4 只读支持

遇到的问题与解决：
- RISC-V 内核栈映射顺序敏感 → 调整 `entry.S` 中栈初始化顺序
- LoongArch 页表 4 级遍历实现复杂 → 参考龙芯手册逐级实现 `walk()`
- QEMU virt 设备树不兼容 → 手动指定设备参数
