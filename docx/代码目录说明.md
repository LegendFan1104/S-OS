# 代码目录说明

项目：SOS (SuperOS)

队伍 ID：T2026104869910625

本文档说明 SOS 仓库的目录结构和各文件的职责。

## 顶层目录

```
sos/
├── Makefile                  # 顶层构建文件（双架构编译入口）
├── README.md                 # 项目说明
├── LICENSE                   # 许可证
├── .gitignore                # Git 忽略规则
│
├── include/                  # 头文件（~60个）
├── kernel/                   # 内核源码（核心 + 文件系统 + 驱动）
├── hal/                      # 硬件抽象层（架构相关汇编 + UART）
├── hsai/                     # 硬件服务抽象接口层
├── user/                     # 用户态 initcode 入口程序
├── tools/                    # 工具与测试配置（4个 shell 脚本）
│
├── docx/                     # 项目文档
│   ├── design/               #   设计文档
│   ├── components/           #   组件文档
│   └── *.md                  #   顶级文档
│
├── sdcard-la.img             # LoongArch 磁盘镜像（含测试用例）
└── sdcard-rv.img             # RISC-V 磁盘镜像（含测试用例）
```

## `include/` — 头文件

```

│   ├── types.h               #   基础类型定义（uint8..uint64, size_t, pid_t, pte_t）

│   ├── process.h             #   进程控制块 proc_t、状态枚举、clone 标志、进程 API
│   ├── thread.h              #   线程控制块 thread_t、状态枚举、线程 API

│   ├── vma.h                 #   VMA 结构体与 API

│   ├── slab.h                #   SLAB 分配器 API
│   ├── spinlock.h            #   自旋锁结构与 API
│   ├── sleeplock.h           #   睡眠锁结构与 API
│   ├── timer.h               #   定时器结构与 API

│   ├── futex.h               #   Futex API

│   ├── print.h               #   打印宏（LOG, DEBUG_LOG_LEVEL, PRINT_COLOR）

│       ├── ext4_xattr.h / ext4_hash.h         # 扩展属性与哈希
│       ├── ext4_crc32.h / ext4_debug.h        # CRC32 与调试

│       ├── list.h / container_of.h            # 工具宏
│       └── vfs_ext4.h / vfs_vfat.h            # VFS 接口

├── hal/                      # HAL 层头文件
│   ├── riscv/
```

## `kernel/` — 内核源码

```
kernel/
├── sos_start_kernel.c        # 内核入口（初始化所有子系统 → scheduler）
├── process.c                 # 进程管理（~1419行，pool, allocproc, scheduler, fork, exit, wait）
├── thread.c                  # 线程池管理（~58行，alloc_thread, thread_init）
├── syscall.c                 # 系统调用实现（~4730行，50+ syscall）
├── exec.c                    # ELF 加载器（~800行，动态链接、shebang、重定向）
├── vmem.c                    # 虚拟内存管理（walk, mappages, uvmalloc, copyin/out）
├── pmem.c                    # 物理内存 Buddy System
├── vma.c                     # VMA 虚拟内存区域管理
├── slab_common.c             # SLAB 小对象分配器
├── spinlock.c                # 自旋锁（push_off/pop_off + 原子指令）
├── sleeplock.c               # 睡眠锁
├── timer.c                   # 定时器（ticks, gettimeofday, nanosleep）
├── signal.c                  # 信号处理（kill, sigaction 等）
├── futex.c                   # 快速用户态互斥量
├── console.c                 # 控制台（chardev_init, consoleintr）
├── string.c                  # 字符串操作
├── socket.c                  # Socket 接口
├── figlet.c                  # ASCII 艺术字
├── test.c                    # 内核内部测试
├── cpu.c                     # CPU 管理
├── driver/                   # 设备驱动
│   ├── riscv/
│   │   ├── virt.c            #   RISC-V VirtIO MMIO 块设备
│   │   └── Makefile
│   └── loongarch/
│       ├── virtio_disk.c     #   VirtIO 块设备（PCI 传输）
│       ├── virtio_pci.c      #   VirtIO-PCI 传输层
│       ├── pci.c             #   PCI 总线枚举
│       └── Makefile
└── fs/                       # 文件系统（28个文件）
    ├── ext4.c                #   EXT4 总控
    ├── ext4_inode.c          #   Inode 读写与分配
    ├── ext4_dir.c            #   目录操作
    ├── ext4_dir_idx.c        #   HTree 目录索引
    ├── ext4_extent.c         #   Extent 树管理
    ├── ext4_balloc.c         #   块分配器
    ├── ext4_ialloc.c         #   Inode 分配器
    ├── ext4_bitmap.c         #   位图操作
    ├── ext4_block_group.c    #   块组描述符
    ├── ext4_super.c          #   超级块读写
    ├── ext4_journal.c        #   JBD2 日志
    ├── ext4_trans.c          #   事务处理
    ├── ext4_xattr.c          #   扩展属性
    ├── ext4_crc32.c          #   CRC32 校验
    ├── ext4_hash.c           #   目录哈希
    ├── ext4_mbr.c            #   MBR 分区表
    ├── ext4_mkfs.c           #   文件系统创建
    ├── ext4_fs.c             #   文件系统注册
    ├── ext4_debug.c          #   调试工具
    ├── blockdev.c            #   块设备抽象
    ├── ext4_blockdev.c       #   EXT4 块设备接口
    ├── bio.c                 #   块 I/O 缓冲区
    ├── ext4_bcache.c         #   块缓存
    ├── file.c                #   文件对象操作（filealloc, fdalloc）
    ├── fs.c                  #   文件系统注册与查找
    ├── pipe.c                #   匿名管道
    ├── inode.c               #   全局 Inode 管理
    ├── list.c / qsort.c      #   工具
    └── Makefile
```

## `hal/` — 硬件抽象层

```
hal/
├── riscv/                    # RISC-V64
│   ├── entry.S               #   内核入口（设置栈、跳转 sos_start_kernel）
│   ├── start.c               #   机器模式启动（无 SBI 时）
│   ├── switch.S              #   上下文切换（保存/恢复 ra, sp, s0-s11）
│   ├── trampoline.S          #   用户态↔内核态蹦床（uservec/userret, sret）
│   ├── kernelvec.S           #   内核态异常向量（分发到 kerneltrap）
│   ├── sbi.c                 #   OpenSBI 接口封装
│   ├── uart.c                #   NS16550 UART 驱动
│   └── Makefile
└── loongarch/                # LoongArch64
    ├── entry.S               #   内核入口（设置 CSR、栈、跳转 sos_start_kernel）
    ├── kernelvec.S           #   内核态异常向量（TLB 重填 + 通用异常）
    ├── merrvec.S             #   机器错误异常向量
    ├── swtch.S               #   上下文切换（保存/恢复 ra, sp, fp, s0-s8）
    ├── tlbrefill.S           #   TLB 缺失重填处理器
    ├── trampoline.S          #   用户态↔内核态蹦床（ertn 返回）
    ├── uart.c                #   LoongArch UART 驱动
    └── Makefile
```

## `hsai/` — 硬件服务抽象接口

```
hsai/
├── hsai_trap.c               # Trap 分发（usertrap, kerneltrap, devintr, hsai_trap_init）
├── hsai_mem.c                # 内存硬件配置（页表激活、TLB flush、DMW 配置）
├── plic.c                    # PLIC 中断控制器（RISC-V only）
├── print.c                   # 内核打印（printf, printfinit, put_char_sync）
└── Makefile
```

## `user/` — 用户态入口

```
user/
├── include/
│   ├── def.h                 #   用户态基础定义
│   ├── userlib.h             #   用户态库函数声明
│   └── usercall.h            #   系统调用封装
├── riscv/
│   ├── user.c                #   RISC-V initcode（打开 /dev/console → exec busybox）
│   ├── usys.S                #   系统调用跳板（ecall）
│   ├── user_initcode.ld      #   链接脚本
│   └── Makefile
├── loongarch/
│   ├── user.c                #   LoongArch initcode
│   ├── usys.S                #   系统调用跳板（syscall 0）
│   ├── user_initcode.ld      #   链接脚本
│   └── Makefile
└── build/
    ├── rv_init_code.h        #   编译后的 RISC-V initcode 字节数组
    └── la_init_code.h        #   编译后的 LoongArch initcode 字节数组
```
